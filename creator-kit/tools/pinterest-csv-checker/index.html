What this checker looks at

  • The header — Pinterest's template is Title, Media URL, Pinterest board, Thumbnail, Description, Link, Publish date, Keywords. Misspelled or extra columns are the most common reason a file is rejected.
  • Lengths — titles up to 100 characters and descriptions up to 500. Longer ones are shortened at a word or sentence break in the corrected file.
  • Media URLs — every pin needs a public, direct link to the image file. Sharing pages from Google Drive, Dropbox or iCloud open a web page, not the image, so Pinterest can't fetch them.
  • Links — the destination must be a full web address starting with https://.
  • Publish dates — the format is YYYY-MM-DDTHH:MM:SS (for example 2026-10-12T14:00:00), and the date must be in the future. Common spreadsheet formats like 2026-10-12 14:00 are converted for you.
  • Duplicates — exact duplicate rows are removed; repeated images or titles are flagged.
  • Boards — you get the list of board names in the file. They must already exist in your account, spelled exactly the same. Names that differ only in capitals or spaces are merged.
  • File size — Pinterest takes up to 200 pins per file; bigger files are split.

How to bulk upload after the check

  1. Use a Pinterest business account (free; you can convert a personal account in settings).
  2. Create every board listed above, with exactly those names.
  3. Open Pinterest, choose Create → Create Pins in bulk and upload the corrected CSV.
  4. Pinterest fetches your images and schedules each pin for its publish date. If a row fails, Pinterest tells you which one — fix that row and upload just the failed rows again.

Menus change from time to time; if a button has moved, Pinterest's help center has the current steps.

Privacy

The checker runs entirely in your browser. Your file is read on your device and the corrected file is created on your device — nothing is uploaded, stored or tracked. You can even use it offline once the page has loaded.
