# SPEC v5 — Marketing site for the "Faceless Creator Kit"

Context: the Faceless Creator Kit is a paid web app (Channel Planner + Pin Factory) for faceless / AI-avatar YouTube creators, ~$29, sold on Payhip. App: https://plazzers.github.io/channel-studio/kit/ (access-code gated). Sales copy, screenshots and covers are in the channel-studio repo under kit/sales/ (clone https://github.com/plazzers/channel-studio.git and copy what you need; read kit/sales/payhip-description.md for honest positioning). The Payhip store/product does not exist yet: use ONE constant `BUY_URL` (placeholder `https://payhip.com/PLACEHOLDER`) and `FREE_URL` (placeholder for a free lead-magnet product) defined in one config file so they can be swapped in one edit; every buy/free link carries `?utm_source=kitsite&utm_medium=<page>&utm_campaign=<slug>`.

Build everything under `creator-kit/` in THIS repo (live at https://plazzers.github.io/links/creator-kit/). Same tech rules as the existing guide sites: static HTML generated by a Python build script (`tools/build_kit_site.py`, reuse patterns from tools/build_guides.py), no frameworks, no external fonts/CDNs, no tracking, fast, accessible, mobile-first, its own clean modern brand matching the kit's sales covers. Add every page to the root sitemap.xml.

## 1. Landing page `creator-kit/`
High-converting but honest: hero (what it is in one line + main screenshot + Buy + "Try the free tools" secondary), problem → solution, the two tools with real screenshots/GIF-like image sequences, "how it works" in 3 steps, what you get, who it's for / not for, requirements, FAQ (from payhip-description.md), price box with a clear Buy button, final CTA. NO fake testimonials, ratings, user counts, income claims or "guaranteed". Optional "Founder note" kept generic (no invented bio). Open Graph image, JSON-LD `Product` WITHOUT ratings/reviews.

## 2. Two FREE mini tools (lead magnets, rank on Google, drive buyers)
- `creator-kit/tools/title-scorer/` — YouTube title scorer (same transparent rules as the kit's title lab: length, number, curiosity words, strong start, caps, clickbait words, keyword) — paste up to 3 titles, see scores + reasons, copy best. CTA: "Plan every video like this → Faceless Creator Kit".
- `creator-kit/tools/pinterest-csv-checker/` — paste/upload a Pinterest bulk-upload CSV → validates header, title ≤100, description ≤500, URLs, dates format/order, duplicates, board names list; shows fixes and offers a corrected download. CTA to the kit's Pin Factory.
Both 100% client-side, shareable, with their own SEO copy (300–600 words of genuinely useful how-to below the tool).

## 3. SEO guides (12 articles, 900–1,500 words each) `creator-kit/guides/<slug>/`
High-intent long-tail topics, e.g.: how to bulk upload pins to Pinterest with a CSV (step by step, with the exact header); Pinterest bulk CSV errors and fixes; how to plan a faceless YouTube channel (weekly workflow); YouTube title formulas that are not clickbait; how to write AI video script prompts that sound human; how to turn chapters into YouTube Shorts; Pinterest for YouTubers: driving traffic to videos and products; how to host images for Pinterest bulk upload with GitHub Pages (free); thumbnail text rules (2–5 words, readability); a weekly content calendar for one-person channels; how to track what works (simple weekly review); selling digital products from a faceless channel (Payhip basics, honest). Accurate, practical, current-as-of-2026 wording without inventing stats; no fake case studies. Each article: TOC, product box (soft), link to the free tools, related articles. Index page with search.

## 4. Pinterest pins for the kit (30 pins)
Using the existing tools/make_pins.py approach, add a third pin style `kit` (the kit's brand) and 30 pins (tips, "how to", tool features, free tools) → `pins/kit/` + `pins/pinterest-bulk-kit.csv` (boards: "Faceless YouTube Tips", "Pinterest Marketing for Creators", "YouTube Growth Tools"), schedule 2/day from 2026-10-12, links to the landing page / free tools / guides with utm_source=pinterest.

## 5. Launch kit (text only, in `creator-kit/launch/LAUNCH-PLAN.md`)
Honest, ready-to-post copy for: 5 Reddit-style value posts (that follow typical self-promo rules — value first, link only where allowed), 3 Facebook/Discord community posts, a Product Hunt listing (tagline, description, first comment), 10 X/Threads posts, an email to send to the free-tool subscribers (welcome + 3-email sequence), and a launch discount suggestion (e.g. 30% off for 7 days, code LAUNCH30) — plus a simple 4-week launch calendar. Also an affiliate pitch (Payhip affiliate program: suggest 30–40% commission) with a short message to send to small creators.

## 6. Checks & delivery
tests/check_kit_site.py: every page has title/description/canonical/OG, internal links resolve, BUY_URL/FREE_URL only from config, banned words (guaranteed, passive income guaranteed, testimonials, "Michelin", "licensed inspector"), sitemap includes all pages, JSON-LD parses, no ratings. Playwright (Chromium preinstalled; don't run `playwright install`) at 390x844 and 1280x800 on landing, both tools (functional tests with sample input), 2 guides; no console errors; screenshots to docs/screens/kit-*.png. Add a small "Tools for creators" link in the footer of the root index only (not on Walter/Sal pages). Commit to main (git pull --rebase before pushing; the weekly autopilot may push to this repo too). After deploy, fetch the landing page, both tools and the sitemap from the live site to confirm.
